# Промпт для LLM — Lab1

LLM: Claude (Claude Code, модель Claude Opus 5.5).

## Версия 1 (исходный промпт)

```text
Создай Telegram-бота на Python — личного ассистента для задач.

ФУНКЦИОНАЛ:
1. Принимает задачи в текстовом виде: любое обычное текстовое сообщение
   (не команда) сохраняется как новая задача.
2. Организует задачи по приоритетам: высокий 🔴, средний 🟡, низкий 🟢.
   - По умолчанию приоритет средний.
   - Если сообщение начинается с «!», приоритет высокий («!» из текста убирается).
   - После добавления задачи бот показывает inline-кнопки 🔴 / 🟡 / 🟢,
     чтобы сразу сменить приоритет одним нажатием.
3. Отправляет напоминания: пользователь указывает время (через N минут или
   в конкретное время ЧЧ:ММ сегодня/завтра), и бот присылает сообщение
   с текстом напоминания. Напоминания не должны теряться при перезапуске бота.
4. Формирует список дел: активные задачи, отсортированные по приоритету
   (сначала высокий), с порядковыми номерами.
5. Простые заметки: сохранить короткую заметку и посмотреть последние заметки.

КОМАНДЫ:
/start — приветствие и краткая инструкция
/help — список команд с примерами
/list — список активных задач по приоритетам
/done <номер> — отметить задачу выполненной (номер из /list)
/delete <номер> — удалить задачу (номер из /list)
/remind <время> <текст> — напоминание. Форматы времени: «30m» (через 30 минут),
    «2h» (через 2 часа), «18:30» (сегодня в 18:30, а если время уже прошло — завтра)
/reminders — список будущих напоминаний
/note <текст> — сохранить заметку
/notes — последние 10 заметок

МАНЕРА ОТВЕТОВ:
- Коротко, дружелюбно, на русском языке, на «ты».
- Эмодзи умеренно: для приоритетов и подтверждений (✅, ⏰, 📝).
- При ошибке ввода — объяснить, что не так, и показать пример правильной команды.

ХРАНИМЫЕ ДАННЫЕ (SQLite, файл bot.db):
- tasks: id, user_id, text, priority (1 — высокий, 2 — средний, 3 — низкий),
  is_done, created_at, done_at
- reminders: id, user_id, chat_id, text, remind_at, is_sent
- notes: id, user_id, text, created_at
Данные каждого пользователя изолированы по user_id.

ТРЕБОВАНИЯ:
- Библиотека python-telegram-bot версии 21+ (async), напоминания — через встроенный JobQueue.
- При старте бот загружает из БД неотправленные напоминания и заново ставит их в очередь.
- Часовой пояс задаётся в .env (TIMEZONE, по умолчанию Europe/Moscow).
- Токен читается из .env (BOT_TOKEN) через python-dotenv; в коде токена быть не должно.
- Бот простой и понятный, весь код в одном файле bot.py.
- Код хорошо прокомментирован (на русском).
- Обработка ошибок: неверные аргументы команд, несуществующий номер задачи,
  глобальный error handler с логированием, чтобы бот не падал.
- Логирование через модуль logging.

Создай файлы:
1. bot.py — основной код
2. requirements.txt — зависимости
3. README.md — инструкция по установке и запуску
4. .env.example — пример конфигурации
```

## Итерации

### Итерация 1 — запуск локально

Код по промпту v1 сгенерирован с первого раза, бот запустился без ошибок.
Проверены: `/start`, добавление задач, смена приоритета кнопками, `/list`, `/done`,
`/remind`, `/reminders`, `/note`, обработка неверного номера задачи.

### Итерация 2 — неверное время напоминаний

**Проблема:** на `/remind 1m Проверить бота` в 20:45 по местному времени бот ответил
«Напомню 16.10 в 18:46». Напоминание пришло вовремя, но время отображалось по Москве,
а я нахожусь в Ташкенте (UTC+5). В `.env` остался часовой пояс по умолчанию.

**Промпт:**

```text
Время в ответе на /remind показывается по Москве, а я в Ташкенте (UTC+5):
бот написал «Напомню в 18:46», хотя у меня было 20:45. Само напоминание пришло вовремя.
1. В ответе на /remind явно показывай часовой пояс, чтобы ошибка настройки была сразу видна.
2. В .env.example добавь подсказку, что TIMEZONE нужно указать свой, и примеры значений.
```

**Результат:** в ответе появился часовой пояс (`Напомню 16.10 в 20:46 (Asia/Tashkent)`),
в `.env.example` — подсказка; в своём `.env` указан `TIMEZONE=Asia/Tashkent`.
